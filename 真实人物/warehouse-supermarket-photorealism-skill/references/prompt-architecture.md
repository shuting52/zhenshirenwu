# Prompt Architecture

推荐层级：

1. Global Style
2. Adult Subject
3. Face / Skin
4. Hair
5. Wardrobe
6. Pose / Anatomy
7. Product Interaction
8. Environment
9. Composition
10. Lighting
11. Camera / Texture
12. Negative Constraints

原则：

- 优先空间关系，避免无意义关键词堆叠。
- 商品必须用明确物理动词描述：grip、hold、support。
- 蹲姿必须分别描述支撑腿、折叠腿、双脚和上半身。
- 仓储环境由高货架、工业横梁、托盘、电子价格牌和水泥地共同建立。
- 手机摄影避免过度浅景深、电影滤镜和影棚打光。
